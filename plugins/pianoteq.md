# Pianoteq 9 (Modartt)

*Status: reported · last checked 2026-08-10*

[Vendor page](https://www.modartt.com/pianoteq)

*Second-hand reports, not a compatibility guarantee — nobody here retested this. Read the [caution](../README.md#read-this-first) before relying on it.*

Pianoteq has a native Linux build, which makes bridging pointless. The claim that
it also works bridged on patched Wine could not be traced to any source that opens,
so it has been withdrawn.

## Native alternative

Pianoteq ships a native Linux build — Modartt lists Linux alongside Windows, macOS
and iOS for Pianoteq 9, standalone and as a plugin. Use it and skip Wine. Checked
2026-08-10 on [modartt.com/pianoteq](https://www.modartt.com/pianoteq).

## Caveats and fixes

- Prefer the native build.
- Correction, 2026-08-10: the 'works bridged on patched Wine' line rested on a
  search snippet with no recorded URL, so it could not be re-opened and checked.
  It is gone. If you have the source, it is worth an issue.
