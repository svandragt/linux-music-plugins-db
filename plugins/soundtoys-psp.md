# Soundtoys / PSPaudioware

*Status: verified · last checked 2026-08-10*

[Vendor page](https://www.soundtoys.com/) · [All plugins](../README.md)

*Second-hand reports, not a compatibility guarantee — nobody here retested this. Read the [caution](../README.md#read-this-first) before relying on it.*

Work, with GUI quirks around resizable interfaces. Reported by several independent users over five years.

## Caveats and fixes

- Expandable GUIs (E27, Crystallizer) can appear in the wrong place after expanding — switch editor hosting mode.
- Invisible cursor on some Soundtoys GUIs; mouse over the resize handle to get it back.
- PSPaudioware vendor page: <https://www.pspaudioware.com/>
