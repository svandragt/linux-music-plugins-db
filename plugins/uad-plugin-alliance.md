# UAD (native plugins)

*Status: reported, mixed · last checked 2026-08-10*

[Vendor page](https://www.uaudio.com/)

*Second-hand reports, not a compatibility guarantee — nobody here retested this. Read the [caution](../README.md#read-this-first) before relying on it.*

Genuinely mixed, and the thread has now been read: one poster could not get the
installer to work at all, another had the plugins running via iLok machine
authorisation and then stopped for stability reasons. Two people, one thread, so
this stays `reported, mixed` rather than being promoted. Nothing in the yabridge
tracker.

## Caveats and fixes

- UAD hardware and its drivers are out of scope — this is about the plugin binaries only.
- The account that worked started with iLok machine authorisation, then 'lots of
  dll's'. The poster could not reconstruct the steps, so there is no recipe here.
- Softube plugins never worked for that same poster.
